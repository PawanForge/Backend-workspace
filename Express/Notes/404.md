## 404 Page — Simple Notes

```js
app.use((req, resp) => {
    const absPath = path.resolve('html_file/404.html');
    resp.status(404).sendFile(absPath);
});
```

### What is the purpose?

This code is used to **show a custom 404 page when the requested URL does not exist**.

### Line by line:

**1. `app.use()`**

* Creates middleware.
* It handles requests that don't match any route.

**2. `path.resolve()`**

* Finds the **full/absolute path** of `404.html`.

**3. `resp.status(404)`**

* Sends **404 status** to the browser.
* `404` means **Page Not Found**.

**4. `sendFile(absPath)`**

* Sends the `404.html` file to the user.

### Example

If your website has:

```text
/          → Home
/about     → About
/contact   → Contact
```

And user enters:

```text
/hello
```

There is no `/hello` route, so Express shows:

```text
404 - Page Not Found
```

### Remember ⭐

> **404 middleware = If the requested page/route doesn't exist, show the custom 404 page.**

**Important:** Keep this code **at the end of all your routes**.
